# BKT-plasma2D

Monte Carlo simulations of a two-dimensional two-component plasma (a Coulomb gas of ±1 charges) with an extra
short-range interaction generated by Majorana modes. The aim is to map how this interaction changes the
Berezinskii–Kosterlitz–Thouless (BKT) transition and the liquid–gas behaviour of the plasma.

## The physics question

Charges ζ, ζ′ = ±1 at distance r interact through

$$
V_{\zeta\zeta'}(r) = -\zeta\zeta' K \ln\frac{r}{\xi} \;-\; k_B T \,\ln\!\left[2\cosh\!\left(\frac{E_0}{k_B T}\, e^{-r/\xi_F}\right)\right].
$$

- With **E₀ = 0** this is the classic 2D Coulomb gas. At low temperature the charges are bound in ± pairs and the
  system is a dielectric; at high temperature the pairs unbind into a conducting plasma. The two are separated by a
  BKT transition, where the inverse dielectric constant jumps from 4k<sub>B</sub>T/K to zero (Nelson–Kosterlitz).
- The **second term** does not depend on the sign of the charges. It is attractive over a range ξ<sub>F</sub> and,
  for large E₀/k<sub>B</sub>T, can turn the short-distance repulsion between like charges into attraction.

Questions: does the nature of the transition change as E₀/k<sub>B</sub>T grows, and do new phases appear, such as
droplets or bound pairs that cluster together while still proliferating?

## The model as simulated

N particles (N/2 of each sign) in a periodic square box of side L, with a hard core of diameter σ (we set ξ = σ).

| Quantity | Definition |
|---|---|
| Density | ρ\* = Nσ²/L² |
| Temperature | T\* = k<sub>B</sub>T/K, and κ = 1/T\* |
| Majorana coupling | E₀\* = E₀/K |
| Range of the Majorana term | ξ<sub>F</sub> = 5σ |

Lengths are measured in units of L (unit box), so σ/L = √(ρ\*/N). Configurations are sampled with weight
exp(−βU), where βU = κU₁ + U₂:

- **U₁**, the logarithmic interaction, is computed by Ewald summation in the unit box (self, real-space and
  reciprocal terms, with α = 4 and cutoffs n<sub>cut</sub> = 1, m<sub>cut</sub> = 5). It also contains the
  polarization term (π/2)|P|², with P = Σ<sub>i</sub> q<sub>i</sub> R<sub>i</sub> evaluated from coordinates in
  [0, L).
- **U₂** = Σ<sub>i<j</sub> −ln cosh[(E₀/k<sub>B</sub>T) e<sup>−r<sub>ij</sub>/ξ<sub>F</sub></sup>], summed over all
  periodic images (the nearest image exactly, the others from a cubic-spline table with total error ≤ 5×10⁻⁵). The
  constant −ln 2 per pair is dropped. U₂ is off when E₀\* = 0.
- **Moves**: each sweep makes N single-particle trial displacements (uniform, ±0.05 L in each coordinate) and
  0.02 N rigid translations of clusters (particles closer than 1.5σ), following Orkoulas and Panagiotopoulos (1994).

## Getting started

The code is in `11.22 Final Version/` and needs [Julia](https://julialang.org) 1.12. From that folder, install the
pinned packages once:

```bash
julia --project=. -e 'using Pkg; Pkg.instantiate()'
```

A small scan (N = 50, two densities, two temperatures, E₀\* = 0 and 0.25):

```bash
julia --project=. Output_Coordinate_Dielectric.jl --write-jobs --N 50 --rho 0.001,0.01 --T 0.05,0.1 --E0 0,0.25
julia --project=. Output_Coordinate_Dielectric.jl --job 0 --output-root Data
```

The first command writes the job table `Dielectric_jobs.csv`; the second runs job 0 and writes its output under
`Data/`. Each state runs 5,000 burn-in and 10,000 production sweeps when E₀\* = 0, and 20,000 + 400,000 sweeps when
E₀\* > 0, so this example takes roughly 40 minutes on one core (about 1.3 ms per sweep at N = 50).

### Larger scans on an HTCondor cluster

`Make_Jobs.jl` turns a parameter file into a folder ready to upload: it splits the scan into jobs of about three
hours and adds the code, the job table, the run script and a submit file.

```bash
julia --project=. Make_Jobs.jl path/to/params.toml
```

Start from `params_Dielectric.toml` (state scan) or `params_FreeEnergy.toml` (free energy). Each axis can be a list
`[0.1, 0.2]`, a single number, `"start:step:stop"`, or `"log:start:stop:points_per_decade"`. On the cluster, copy
the contents of the generated `upload/` folder into a new folder (no spaces in its name) whose parent directory also
holds `julia-1.12.6-linux-x86_64.tar.gz`, then run `condor_submit Dielectric.sub` (or `FreeEnergy.sub`) inside it.

## Code

| File | Role |
|---|---|
| `Setup.jl` | Box geometry, hard-core checks, random initial configuration |
| `Plasma_Interaction.jl` | Ewald energy, Majorana term, and their changes for single-particle and cluster moves |
| `Monte_Carlo.jl` | Metropolis sampler for one state |
| `one_over_epsilon0.jl` | Fourier modes of the charge and number densities, 1/ε(k) |
| `Output_Coordinate_Dielectric.jl` | State-scan driver and output writer |
| `Free_Energy.jl`, `Output_FreeEnergy.jl` | Free energy by integration from the hard-disk fluid to the full interaction (10 Gauss–Legendre nodes) |
| `Make_Jobs.jl`, `run_*.sh`, `*.sub` | Job packing and HTCondor submission |

## Output of a state scan

Each job writes one folder containing:

| File | Contents |
|---|---|
| `metadata.toml` | Settings, definitions, file layout and SHA-256 hashes of the source files |
| `states.csv` | One row per state: parameters, seed, and byte offsets into the binary files |
| `progress.csv` | One row per finished state; only states listed here are complete |
| `series.f64` | Per sample, 23 little-endian Float64: U₁, U₂, βU, then \|ρ<sub>m</sub>\|² and \|Q<sub>m</sub>\|² for the 10 shells m² = 1, 2, 4, 5, 8, 9, 10, 13, 16, 17 |
| `coordinates.f64` | 100 snapshots per state: x[1:N] then y[1:N], in units of L |
| `charges.f64` | The N charges of each state, in the same particle order |

## Observables

With wave vectors k = 2πm/L, the Fourier sums ρ<sub>m</sub> = Σ<sub>j</sub> e<sup>2πi m·R<sub>j</sub></sup> and
Q<sub>m</sub> = Σ<sub>j</sub> q<sub>j</sub> e<sup>2πi m·R<sub>j</sub></sup> give

$$
S_{NN}(k) = \langle |\rho_m|^2 \rangle, \qquad
S_{QQ}(k) = \langle |Q_m|^2 \rangle, \qquad
\frac{1}{\varepsilon(k)} = 1 - \frac{\kappa\, S_{QQ}(k)}{2\pi m^2},
$$

averaged over the directions of each shell. We do not divide by N: an ideal gas has S<sub>NN</sub> = N. (The
definitions written into `metadata.toml` include a 1/N; the stored numbers do not.)
The BKT transition is located where 1/ε at the smallest wave vector equals 4T\*. S<sub>NN</sub> at small k picks up
droplets and density fluctuations on the scale of the box.
